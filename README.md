# Multikoszyk – prototyp

Klikalny prototyp. LP odtworzony z Figmy (Multikoszyk, węzeł 6576:13806) razem z obrazami w `assets/lp/`; koszyk wywodzi się z artifactu https://claude.ai/artifact/Qmx5Rh9rmg4HHeANpVrrJi, ale to repo jest teraz wersją główną. Ceny i opisy usług są przykładowe.

Przepływ:
- LP ze światłowodem – przełączniki TV z Amazon Prime / Netflix, czas umowy, kafle prędkości.
- „Sprawdź dostępność” – plansza ładowania na 3 sekundy.
- Koszyk – usługi dodawane w panelu bocznym, podsumowanie opłat przeliczane na żywo, licznik abonamentów komórkowych, demo z animowanym kursorem.

Strona statyczna: `index.html` + obrazy w `assets/lp/`. Dostęp chroniony hasłem przez `middleware.js`.
